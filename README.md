# Saara Bashirkhel website

A static website ready for deployment on Vercel.

## Publish it

1. Create a new empty GitHub repository (for example, `saara-bashirkhel-website`).
2. Upload all files in this folder to the repository root and commit them.
3. In Vercel, choose **Add New → Project**, import that GitHub repository, then choose **Deploy**. No build settings are required.
4. In Vercel's project settings, add your custom domain when you are ready.

## Update business details

The phone and WhatsApp link are in `index.html`. Change the copy, products, and images there whenever needed.
